ACS-1

Adaptive Carrier System

The ACS-1 is Axiom's modular armour carrier concept. The platform can be configured with different cummerbunds, front panels and accessory packages around a common carrier.

01 MODULAR

Interchangeable components allow the basic carrier configuration to be altered.

02 SCALABLE

Build from a simple carrier into a more complete load carriage system.

03 INTEGRATED

Accessories are designed around the same basic equipment platform.

DESIGN // 02

Less,
done better.

The ACS-1 concept uses a simple base carrier with removable components rather than treating every configuration as a completely separate product.

A common platform allows load carriage, communications equipment and additional components to be integrated around the requirements of the user.
