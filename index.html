HOW DOES THIS WORK?

Sanderson Digital is currently published as an encrypted static document. The access credential is used locally in the browser to derive the key required to decrypt the page.

This arrangement is being used to restrict casual access to an unfinished personal website during development. It should not be treated as a replacement for server-side authentication where genuinely sensitive information is involved.
